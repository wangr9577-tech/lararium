# 白板书写体验第三阶段：确定性矢量美化

> 状态：实施方案，尚未编码  
> 依赖：第一阶段分层渲染、第二阶段高保真采样  
> 核心原则：美化可以修正抖动，不能改变字义；结果必须可撤回，原始采样必须保留

## 1. 阶段目标

本阶段不依赖服务器和 GPU，在浏览器 Worker 中完成落笔后的矢量优化：去抖、等距重采样、转折保护、贝塞尔拟合和压力轮廓重建。

美化发生在 `pointerup` 后，不进入笔尖实时反馈链路。湿墨先按第二阶段方案即时显示，确定性美化结果在短时间内替换湿墨并提交干墨层。

### 1.1 用户可见模式

| 模式 | 行为 |
|---|---|
| 原笔 | 不改变位置，只使用正常笔刷轮廓 |
| 稳定 | 去除高频抖动，保留原始转折和笔画形状；推荐默认 |
| 美化 | 进一步拟合曲线和统一压力，但仍受严格位移约束 |

每种模式提供强度控制。默认“稳定”建议处于 20%～30%，不应默认开启强修正。

## 2. 非目标

- 不识别字符内容。
- 不把手写内容替换成字体。
- 不重新安排笔顺。
- 不连接原本分开的笔画。
- 不删除疑似“多余”的点、撇、捺、标点。
- 不处理整行排版、字距统一或基线对齐；这些属于第四阶段可选能力。

## 3. 为什么使用确定性算法

实时字迹美化失败通常不是因为曲线不够平滑，而是因为过度平滑改变了：

- 中文横折、竖钩等尖锐转折；
- 很短的点、提、撇；
- 数学符号的小间隙；
- 字母交叉和笔画自交；
- 用户有意保留的速度和压力变化。

确定性算法可以设置硬约束、编写单元测试并保证相同输入得到相同输出。它应作为 AI 之前的可靠基线，也作为 AI 不可用时的永久降级路径。

## 4. 处理管线

```text
Raw samples
  -> 数据校验和异常点剔除
  -> 屏幕尺度归一化
  -> 等弧长重采样
  -> 特征计算（速度、曲率、转角、压力梯度）
  -> 锚点检测（端点、转折、自交附近、停顿点）
  -> 受锚点约束的自适应平滑
  -> 分段三次贝塞尔拟合
  -> 压力/倾角重采样
  -> 几何约束检查
  -> 生成最终笔刷轮廓和边界
```

任一步骤失败、超时或违反几何约束时，返回第二阶段的稳定滤波结果，不阻塞保存。

## 5. 数据表示

### 5.1 原始数据与渲染数据分离

推荐 v3 笔迹结构：

```ts
interface BeautifyMeta {
  engine: 'none' | 'vector-v1'
  strength: number
  version: number
  status: 'raw' | 'refined' | 'fallback'
}

interface StrokeV3 {
  id: string
  tool: Tool
  color: string
  w: number
  tip?: TipKey
  rawPts: InkSampleV3[]
  pts: InkSampleV3[]
  curve?: CubicSegment[]
  beautify?: BeautifyMeta
  rev: number
}
```

约定：

- `rawPts` 是不可变事实来源。
- `pts` 是当前渲染点；未美化时可与 `rawPts` 相同。
- `curve` 是可选缓存，可由 `pts` 重建。
- 重新调节强度必须从 `rawPts` 计算，不能对已美化结果反复美化。
- 原始数据用于撤回、算法升级和第四阶段个性化训练。

### 5.2 内容体积

同时保存 raw 和 refined 会增加 JSON 大小。采用以下控制：

- `rawPts` 使用相对时间和定点量化；
- 连续坐标可在序列化时 delta 编码；
- `pts` 若与 `rawPts` 完全相同则省略；
- `curve` 是缓存，可选择不持久化；
- base64 PDF/PPT 底图已占用大量正文体积，不能再引入无界冗余。

第一版可先直接保存数组以降低实现风险，同时增加 payload 大小指标；超过阈值后再引入编码。

## 6. 算法细节

### 6.1 输入校验

剔除或修正：

- `NaN`、`Infinity`；
- 页面范围外过远的点；
- 时间倒退；
- 完全重复点；
- 单次位移远超设备合理速度的孤立跳点；
- pressure 超出 `[0, 1]` 的值。

边界附近允许轻微越界，最终由页面裁剪，不要粗暴把每个点 clamp 到边缘，否则会形成沿边直线。

### 6.2 等弧长重采样

原始 PointerEvent 的时间间隔不均匀。先沿累计弧长重采样，后续曲率和拟合才稳定。

建议间隔按屏幕像素和笔宽共同决定：

```text
spacingPx = clamp(0.35 * strokeWidthPx, 0.4, 1.5)
```

- 小字、细笔使用更小间隔。
- 快速长线无需保留每个原始点。
- 转角两侧必须保留额外点，不能被均匀采样抹平。

### 6.3 特征计算

对每个重采样点计算：

- 一阶速度和速度变化；
- 局部方向；
- 三点夹角；
- 离散曲率；
- pressure 梯度；
- 原始时间停顿；
- 到端点的距离。

这些特征只在 Worker 内存在，不必全部持久化。

### 6.4 锚点检测

以下点不能被普通平滑移动：

1. 起点和终点。
2. 夹角或曲率超过阈值的转折。
3. 用户明显停顿后改变方向的位置。
4. 距离自交点很近的位置。
5. 很短笔画的中心点。
6. pressure 快速改变且伴随速度变化的位置。

锚点不是完全禁止移动，而是使用更小的最大位移和更高权重。

### 6.5 自适应平滑

分段处理相邻锚点之间的点：

- 低曲率长段允许更强平滑；
- 高曲率、小字和低速段降低平滑；
- 距离锚点越近，修正越弱；
- 不跨锚点卷积或平均；
- 对 x/y 和 pressure 使用不同参数。

美化强度 `s in [0,1]` 映射到最大允许位移：

```text
maxShiftPx = min(0.35 * strokeWidthPx + 1.2 * s, 2.5)
```

最终实现需根据真机 DPI 换算到物理毫米，默认最大位移目标约 `0.3～0.8 mm`，强模式也不应超过约 `1.2 mm`。

### 6.6 贝塞尔拟合

使用三次贝塞尔曲线拟合平滑后的折线，可参考 MIT 许可的 [fit-curve](https://github.com/soswow/fit-curve)。

要求：

- 每两个锚点之间单独拟合。
- 误差阈值随笔宽和美化强度变化。
- 转折点两侧切线独立，不能强制连续成圆角。
- 极短段直接使用线段或二次曲线。
- 拟合失败时保留平滑折线。

不要使用单纯 Ramer-Douglas-Peucker 简化后直接渲染，它可能删除中文小钩和短折。若使用 [simplify-js](https://github.com/mourner/simplify-js)，只能用于生成初始候选点，且必须经过锚点保护。

### 6.7 压力重建

位置曲线确定后，按弧长把原始 pressure、tilt、twist 插值到 refined 点或曲线参数上。

规则：

- 保留整体压力趋势；
- 过滤单点尖峰；
- 转折附近限制宽度变化速度；
- 起笔和收笔单独处理；
- 不凭空增加用户未输入的强压效果。

### 6.8 自交和拓扑保护

美化前后计算粗略拓扑特征：

- 自交次数；
- 包围盒；
- 端点距离；
- 总弧长；
- 主要方向变化序列。

若出现以下情况则降低强度或回退：

- 自交次数改变；
- 包围盒某一维变化超过阈值；
- 端点移动超限；
- 总弧长缩短过多；
- 曲线跨越相邻但原本分离的笔画区域。

## 7. 特殊笔画

### 7.1 点和短笔

少于 3 个有效点或长度小于约 1.5 个笔宽时视为点：

- 不做贝塞尔拟合；
- 保留落笔位置；
- 只修正异常压力和椭圆方向；
- 不能因“过短”被删除。

### 7.2 长直线

若曲率持续很低：

- 可以加强横向去抖；
- 不能自动吸附到水平/垂直，除非用户开启单独的“形状辅助”功能；
- 保留轻微自然变化，避免机械感。

### 7.3 闭合曲线

首尾接近且方向连续时可做闭合拟合，但必须保持原来的开闭状态。不能把相近端点自动连接。

### 7.4 荧光笔和橡皮

- 荧光笔只做中心线稳定和端部处理，不追求书法笔锋。
- 橡皮轨迹不做美化；擦除应基于用户真实轨迹，避免误删。

### 8.1 消息协议

```ts
type BeautifyRequest = {
  kind: 'beautify'
  requestId: string
  strokeId: string
  strokeRevision: number
  page: { w: number; h: number }

type BeautifyResponse = {
  requestId: string

  ok: boolean
  points?: InkSampleV3[]
  curve?: CubicSegment[]
  metrics?: BeautifyMetrics
  fallbackReason?: string
}
```

### 8.2 并发和取消

- 每条笔迹拥有递增 revision。
- 用户撤销、擦除或重新美化后，旧 response 必须丢弃。
- Worker 不需要强制终止正在计算的短任务，但客户端必须取消其提交资格。
- 连续快速书写时按完成顺序提交各自结果，不得让前一笔阻塞新一笔湿墨。
- 队列超过阈值时优先处理最近和可见笔迹，旧笔迹可稍后空闲处理。

## 9. 湿墨到美化结果的过渡

直接替换路径可能让用户看到字迹突然跳动。采用短过渡：

1. `pointerup` 后立即用第二阶段输出提交临时干墨。
2. Worker 返回 refined 结果。
3. 检查 revision 和几何约束。
4. 在 `60～100 ms` 内做 alpha crossfade。
5. 过渡结束后释放旧临时路径。

若 refined 与原始最大位移很小，可以直接替换，避免额外合成成本。

## 10. UI 与操作语义

工具栏增加紧凑控制：

- 三段式：原笔 / 稳定 / 美化。
- 强度：仅在稳定或美化模式显示。
- 对选中笔迹提供“恢复原笔”和“重新美化”。
- 设置作为新笔迹默认值，不自动重写全部历史笔迹。

撤销语义：

- 自动美化是同一笔提交的一部分，不额外占用一次撤销。
- 用户手动重新美化属于显式编辑，应进入撤销栈。
- “恢复原笔”也属于显式编辑，应可撤销。

## 11. 性能目标

| 类型 | Worker P95 目标 |
|---|---|
| 普通短笔（< 200 点） | `< 20 ms` |
| 普通长笔（< 1000 点） | `< 50 ms` |
| 极长笔 | `< 150 ms`，允许分段或降级 |
| 主线程处理 response | `< 3 ms` |

Worker 耗时不计入笔尖实时延迟，但不能长期占满 CPU 或造成页面电量消耗异常。

## 12. 测试与评价

### 12.1 几何不变量

每条测试轨迹检查：

- 起点、终点位移；
- 最大点位移和 Hausdorff 距离；
- 自交次数；
- 包围盒变化；
- 总弧长变化；
- 锚点保留率；
- pressure 范围和单步变化。

### 12.2 黄金轨迹

至少包含：

- 中文：横、竖、撇、捺、点、横折、竖钩、复杂多折；
- 英文：`m/w/e/s/g` 和连写；
- 数学：`+ - = ∫ Σ √`、上下标；
- 图形：圆、箭头、波浪线；
- 标点和极短笔；
- 真实压感与模拟压感两组。

黄金测试不要求像素完全一致，而检查曲线控制点、几何约束和渲染快照的容差。

### 12.3 主观盲测

同一组轨迹随机展示原笔、稳定、美化三个版本，评价：

- 更稳但是否仍像本人；
- 转折是否被磨圆；
- 小字是否粘连；
- 是否出现“橡皮筋”式回弹；
- 是否愿意把该模式设为默认。

主观偏好必须与几何安全指标同时通过。

## 13. 实施步骤

### P3.1 数据和回放基础

- 保存 raw/refined 分离数据。
- 建立轨迹录制和离线回放工具。
- 建立几何指标函数。

### P3.2 重采样和锚点

- 完成等弧长重采样。
- 实现速度、曲率和停顿特征。
- 实现端点/转角/自交锚点。

### P3.3 稳定模式

- 实现受锚点约束的自适应平滑。
- 先上线“稳定”，不做曲线拟合。
- 真机调节默认强度。

### P3.4 美化模式

- 接入贝塞尔拟合。
- 实现压力重采样和拓扑保护。
- 增加回退原因统计。

### P3.5 UI、撤销和迁移

- 增加三段式模式和强度。
- 实现恢复原笔、重新美化。
- 完成 v3 payload 和旧数据迁移。

## 14. 发布策略

- 第一版默认“稳定 20%”，美化模式默认关闭。
- feature flag 可整体关闭 Worker 美化。
- Worker 崩溃、超时或约束失败时回退原笔。
- 不在上线时批量重写历史笔迹。
- 算法版本写入 stroke meta；升级算法不自动改变旧笔迹。

## 15. 验收清单

- [ ] 美化不进入 pointerdown→湿墨实时链路。
- [ ] 原始采样永久保留，可恢复原笔。
- [ ] 中文尖锐转折、短点和数学符号不被删除或磨圆。
- [ ] 自交和开闭状态不发生变化。
- [ ] Worker 结果通过 revision 检查，不会覆盖已撤销笔迹。
- [ ] 普通笔迹 Worker P95 达到性能目标。
- [ ] 自动美化不额外增加撤销步骤。
- [ ] 关闭 feature flag 后基本书写、保存和导出不受影响。
