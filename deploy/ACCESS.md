# Kruskal 访问指南（仅 127.0.0.1 + 隧道）

服务只监听 `127.0.0.1:18080`（服务器本机），任何网络（含跨子网/校外）都通过"隧道"访问，**不需要对服务器开任何入站端口**。

## 方式一：SSH 隧道（校内/能 SSH 到服务器时）

在你自己的电脑上执行（Windows 用 PowerShell / CMD / MobaXterm / VS Code Remote-SSH）：

```bash
ssh -N -L 18080:127.0.0.1:18080 stu_wr@192.168.2.222
```

然后浏览器打开：http://127.0.0.1:18080

> 隧道窗口保持开着才能访问；可配 autossh / VS Code Remote-SSH 常驻。

### 平板 / 手机：SSH 隧道 App（与电脑同理，服务端零改动）

平板/手机和电脑一样，装一个支持「本地端口转发 (Local Forward)」的 SSH 客户端 App，让设备自己建隧道：

1. **安卓**：装 ConnectBot（免费开源，支持端口转发）；Termius 界面更好但端口转发部分功能需订阅，免费可用 ConnectBot。
2. 新建主机：`stu_wr@192.168.2.222:22`，认证用 SSH 密码或导入电脑所用的私钥（服务器已开 `publickey,password` 两种认证）。
3. 给该主机添加端口转发：**本地端口 `18080` → 目标 `127.0.0.1:18080`**（类型 local）。
4. 保持 App 连接不退出（别被系统杀掉后台），然后浏览器打开：http://127.0.0.1:18080
5. 断开连接即失效，需要时重新连。

> 跨子网但能 SSH 通服务器（如校园网不同子网）时同样适用，不要求与服务器同一网段。

## 方式二：校外/任何网络（出站隧道，服务器无需公网入站）

服务器出口有公网 IP，但校园网管理策略隔离了入站；因此让"服务器主动连出去"的方案最稳，二选一：

### A. Cloudflare Quick Tunnel（零账号，先试水）
```bash
# 在服务器上下载 cloudflared（GitHub 可达）并运行：
cloudflared tunnel --url http://127.0.0.1:18080
# 会打印一个 https://xxxx.trycloudflare.com 地址，任何网络都能打开（需登录密码）
```
- 优点：不用账号、不用域名、HTTPS 自带
- 缺点：免费 Quick Tunnel 地址每次重启会变；要固定域名需自己的域名 + 实名（Cloudflare 免费档可用）

### B. Tailscale（长期自用推荐）
两端（服务器 + 你的电脑/手机）都装 Tailscale，加入同一账号即可，像"私人专网"一样直连：
- 跨子网、跨运营商、校外都能访问；端到端加密
- 服务仍可保持绑 127.0.0.1，用 `tailscale serve` 转发到站点，或用 KRUSKAL_HOST 绑 100.x 内网 IP

> 注意：校园网若封锁 QUIC/UDP 出站，A/B 可能受影响（A 会退化为普通 TLS，一般没事）；届时可换 frp + 自己的 VPS。

## 账号

- 初始账号：`admin`；初始密码见服务器 `backend/data/initial_password.txt`（登录后请立即在 设置 → 账户安全 修改）
- 站点任何时候都要求登录；走公网隧道时请务必使用强密码（数据仍加密存储）
- 登录有防爆破限流：同一 IP（或同一用户名）10 分钟内失败 10 次 → 429 冷却 10 分钟；走隧道时若多设备共享同一出口，连续输错注意别攒满
