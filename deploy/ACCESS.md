# Kruskal 访问说明

Kruskal 现在是**单机单人应用**：没有登录、没有账号体系，浏览器打开后自动建立本机会话。

- 服务只监听 `127.0.0.1:18080`，请在本机浏览器打开 <http://127.0.0.1:18080/>。
- **不要**通过 SSH 隧道、Cloudflare、Tailscale、frp 等方式把端口转发出去：没有登录这一层，任何能打开该地址的人都可以直接读写全部数据（包括日记、相册、账本）。
- 如果确实需要在另一台设备上查看，请先关闭服务，把数据目录整体复制过去，在那台机器的本机启动。

数据与备份见根目录 `README.md`；备份/还原脚本是 `deploy/backup.sh`、`deploy/restore.sh`。`kruskal.service` 仅作为「本机开机自启」示例保留，不要改成对外监听。
